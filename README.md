# Relic Grove: Archive Frontier

Canvas RPG/action game with movement, combat, gathering, inventory, shop upgrades, and boss clearing.

## Install

```bash
npm install
```

## Run

```bash
npm run dev
```

## Build

```bash
npm run build
```

## Test

```bash
npm test
```

## Liivo Deployment

Build command: `npm run build`

Static output: `dist`

After deployment, add the Liivo URL to Noel's Game Hub under `relic-grove-archive-frontier`.
